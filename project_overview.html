🎯 Project Overview

🤖

What It Is

A complete control system for a 3-DOF PUMA 560 robotic arm that uses both analytical inverse dynamics (CTC) and learned neural network models (DNN) for precise trajectory tracking.

🧠

The Innovation

A hybrid DNN controller: DeLaN (physics-aware Lagrangian network in JAX) provides a principled baseline, while a GRU residual network (PyTorch) corrects for unmodelled dynamics.

⚙️

Simulation Stack

ROS 2 Humble + Gazebo Fortress with ros2_control. 3 effort joint controllers running at 100 Hz, commanded by a Python node computing full inverse dynamics in real-time.

📊

Goal

Show that a DNN trained offline on simulated inverse dynamics data can match or outperform a hand-tuned PID+CTC controller, especially on novel trajectories it hasn't seen before.

🔢 Control Algorithms

The Computed Torque Control law decomposes the robot dynamics into a model-based feedforward term and a feedback correction term:

Full CTC Control Law τ = D(q)·q̈des + C(q,q̇)·q̇ + G(q) + Kp·e + Kd·ė + Ki·∫e dt

D(q) — Inertia Matrix

3×3 configuration-dependent mass/inertia matrix. Encodes how much torque is needed to produce acceleration at each joint given the current pose.

C(q,q̇) — Coriolis/Centrifugal

Velocity-dependent coupling terms. Accounts for rotational kinetic energy interactions between links. Computed via Christoffel symbols.

G(q) — Gravity Vector

Torques needed to hold the arm against gravity at configuration q. Largest component in slow trajectories.

PID Feedback

Kp·e corrects steady-state error. Kd·ė damps oscillations. Ki·∫e removes persistent bias from model inaccuracies.

Three Operating Modes

FlagModel TermFeedback TermUse Case
default✅ Full D,C,G✅ Kp/Kd/KiNormal operation
--no-feedback✅ Full D,C,G❌ OffEvaluate model accuracy alone
--no-model❌ Off✅ Kp/Kd/KiBaseline PD-only performance

Default Gains

Python — torque_publisher_ctc.py
# Per-joint: [joint1, joint2, joint3] Kp = [30, 100, 50] # Proportional Kd = [4, 10, 5] # Derivative Ki = [0.2, 1.0, 0.8] # Integral (small, bias removal)

The DNN controller replaces the analytical D,C,G computation with two neural networks working in tandem:

DNN Control Law τ = τDeLaN + τGRU + Kp·e + Kd·ė + Ki·∫e dt
⚡

DeLaN (JAX/Haiku)

Deep Lagrangian Network. Physics-aware architecture that encodes energy conservation laws. Input: q, q̇, q̈. Runs every timestep from step 0.

🔁

GRU Residual (PyTorch)

4-layer GRU with 64 hidden units. Takes 128-step rolling history of [q, q̇, q̈, τ_delan]. Learns corrections to DeLaN. Activates at step 128 (1.28s warmup).

Warmup Behaviour

Steps 0 → 127  (1.28 seconds)
  τ = τ_DeLaN + Kp·e + Kd·ė + Ki·∫e
  GRU builds rolling history buffer (no output)

Steps 128+  (normal operation)
  τ = τ_DeLaN + τ_GRU_residual + Kp·e + Kd·ė + Ki·∫e
  Tracking error typically drops 20–50% after GRU activates

DNN Feedback Gains (Lower Than CTC)

Python — torque_publisher_dnn.py
# Reduced gains — DNN handles most of the feedforward Kp = [5, 20, 10] # ≈ 1/5 of CTC values Kd = [1, 3, 2] # ≈ 1/3 of CTC values Ki = [0.05, 0.2, 0.1]

Trajectories are generated as 5th-order polynomial (minimum-jerk / S-curve) profiles that guarantee zero velocity and acceleration at start and end:

5th-Order Polynomial (Minimum Jerk) f(τ) = 10τ³ − 15τ⁴ + 6τ⁵   where τ = t/T ∈ [0,1]

Boundary Conditions

f(0)=0, f(1)=1  |  f'(0)=f'(1)=0  |  f''(0)=f''(1)=0

Zero velocity AND acceleration at endpoints — smooth start/stop.

Timing Constraints

T ≥ 1.875×max(Δq)/v_max  (velocity)
T ≥ √(5.77×max(Δq)/a_max)  (accel)

v_max=2.0 rad/s, a_max=7.0 rad/s²

Output Format

CSV at 100 Hz sampling. 10 rows: t, dp1-3, dv1-3, da1-3. Duration options: 12, 16, 20, 24 seconds. 1200–2400 columns per file.

📅 Project Progression

Phase 1 — Foundations

Robot Modelling & Simulation Setup

Built 3-DOF PUMA 560 URDF in xacro format with accurate DH parameters, link masses, and inertia tensors including motor inertias. Integrated with ROS 2 Humble + Gazebo Fortress. Configured 3 effort joint controllers at 100 Hz via ros2_control.

Phase 2 — Dynamics

Symbolic Inverse Dynamics Implementation

Derived full D(q), C(q,q̇), G(q) symbolically using SymPy (inverse_dynamics_model.py). Compiled to numpy lambdas for real-time evaluation. Also developed MATLAB scripts for verification. This became the backbone of the CTC controller.

Phase 3 — Trajectory

S-Curve Trajectory Generator

Implemented 5th-order polynomial minimum-jerk profiles (gen_traj.py). Added automated timing calculation to respect joint velocity and acceleration limits. Supports random endpoint generation for diverse training data.

Phase 4 — CTC Controller

Full Computed Torque Controller (ctc_added_0/1 commits)

Implemented torque_publisher_ctc.py (866 lines) with stabilization phase, trajectory phase, 3 operating modes (full/feedforward-only/feedback-only), automatic log saving, and configurable gains via CLI. Tested on multiple pre-generated trajectories.

Phase 5 — Data Pipeline

Inverse Dynamics Data Collection Pipeline

Built id_pipeline/ with 2-step workflow: execute trajectory in Gazebo and record actual torques, then post-process with Butterworth LPF (30 Hz) and Savitzky-Golay acceleration estimation. Generates clean training datasets including τ_ID columns.

Phase 6 — Neural Networks

DeLaN + GRU Residual Network Training

Trained DeLaN (physics-informed Lagrangian NN) in JAX/Haiku on collected datasets. Trained GRU residual network (4 layers, 64 hidden, 128-step history) in PyTorch to learn corrections to DeLaN predictions. Models saved as .jax and .pt files.

Phase 7 — DNN Controller (latest)

Online DNN Inference Controller (dnn_controller_0/1 commits — Apr 27)

Implemented torque_publisher_dnn.py with online real-time inference of both DeLaN and GRU models. Handles warmup phase (128 steps) gracefully. Includes full analysis tooling (analyze_dnn_performance.py) for comparison against CTC baseline.

Phase 8 — In Progress

Evaluation & Thesis Write-up

Comparative performance studies between CTC and DNN controllers across multiple trajectories. Generating publication-quality plots, metrics, and analysis for the final thesis submission.
