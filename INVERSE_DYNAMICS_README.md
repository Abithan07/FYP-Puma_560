# PUMA-560 Inverse Dynamics Calculator

This package provides Python tools to compute inverse dynamics (torques, inertia effects, Coriolis effects, and gravity effects) from PUMA-560 joint trajectories generated by `trajectory_generator.py`.

## Overview

Three implementations are provided:

1. **`inverse_dynamics_calculator.py`** - Symbolic approach using SymPy
   - Most accurate but slowest
   - Pre-derives all dynamics equations symbolically
   - Best for research/validation

2. **`inverse_dynamics_calculator_numerical.py`** - Numerical differentiation approach
   - Balanced accuracy and speed
   - Uses finite differences throughout
   - Good for most applications

3. **`inverse_dynamics_fast.py`** - Optimized numerical approach (RECOMMENDED)
   - Fastest implementation
   - Analytical angular Jacobians + numerical linear Jacobians
   - Recommended for production use

## Usage

### Quick Start

Generate a trajectory, then compute inverse dynamics:

```bash
# 1. Generate a trajectory
python3 trajectory_generator.py 1 --q-end-deg 115.0 0.0 90.0 --t-total 15.0 --path-id 5600

# 2. Compute inverse dynamics (recommended: fast version)
python3 inverse_dynamics_fast.py Dataset/Trajectories/path_5600_traj.csv -o Dataset/Joint_states
```

| Row | Label | Contents |
|-----|-------|----------|
| 1 | `t` | Time vector |
| 2-4 | `dp1, dp2, dp3` | Joint positions (q1, q2, q3) in radians |
| 5-7 | `dv1, dv2, dv3` | Joint velocities (dq1, dq2, dq3) |
| 8-10 | `da1, da2, da3` | Joint accelerations (ddq1, ddq2, ddq3) |
| 11-13 | `tau1, tau2, tau3` | **Computed torques** (N⋅m) |

## Inverse Dynamics Formula

The torques are computed using the Lagrangian inverse dynamics formula:

$$\tau = D(q) \ddot{q} + C(q,\dot{q})\dot{q} + G(q)$$

Where:
- **D(q)** = Inertia matrix (3×3)
- **C(q,dq)** = Christoffel symbols tensor (3×3×3)
- **G(q)** = Gravity vector (3×1)

The three terms represent:
- **Inertial torques**: D(q)⋅ddq (effort needed to accelerate the links)
- **Coriolis/Centripetal torques**: C(q,dq)⋅dq (gyroscopic and centrifugal effects)
- **Gravity torques**: G(q) (effort needed to maintain the configuration against gravity)

## Python API Usage

You can also use the calculator programmatically:

```python
from inverse_dynamics_fast import InverseDynamicsCalculator
import numpy as np

# Initialize calculator
calc = InverseDynamicsCalculator()

# Define joint state
q = np.array([0.0, 0.785, 2.356])          # Joint positions (radians)
dq = np.array([0.0, 0.0, 0.0])             # Joint velocities
ddq = np.array([0.018, 0.018, 0.018])      # Joint accelerations

# Compute torques
tau, M, C_vec, G_vec = calc.compute_torques(q, dq, ddq)

print(f"Torques: {tau}")
print(f"Inertia term: {M}")
print(f"Coriolis term: {C_vec}")
print(f"Gravity term: {G_vec}")
```

## Validation

To validate the inverse dynamics computation, check the relationship:

$$\tau_{computed} = D(q) \ddot{q} + C(q,\dot{q})\dot{q} + G(q)$$

Each output file contains all three components, allowing you to verify:

```python
import numpy as np

# Load output
data = np.loadtxt('path_5600_joint_states.csv', delimiter=',', skiprows=10, usecols=range(1, 100))

# Verify computation
tau = data[10]      # tau1, tau2, tau3
M = data[13]        # m1, m2, m3
C = data[16]        # c1, c2, c3
G = data[19]        # g1, g2, g3

# Check if tau ≈ M + C + G
computed_tau = M + C + G
residual = np.abs(tau - computed_tau)
print(f"Max residual: {np.max(residual)}")  # Should be small (~1e-10)
```

## Troubleshooting

### Script is too slow
- Use `inverse_dynamics_fast.py` instead of the symbolic version
- Reduce trajectory length if testing

### Numerical instability
- If residuals are large, check joint angles are within PUMA limits
- Verify input trajectory is physically feasible

### Memory issues
- Process trajectories one at a time instead of entire directory
- Use a machine with more RAM for batch processing
