🎯 CONTROL LAW IMPLEMENTED
═══════════════════════════════════════════════════════════════════════════════════

COMPUTED TORQUE CONTROL LAW:

    τ = D(q)·q̈ + C(q,q̇) + G(q) + Kp·(q_des - q_act) + Kd·(q̇_des - q̇_act)
        └──────────────────────────┬──────────────────────────┘     └──────────────┬──────────────┘
                    Model-based feedforward                              Feedback control

WHERE:
  • D(q)    = Inertia matrix (3×3), computed from robot geometry
  • C(q,q̇) = Coriolis/centrifugal vector, from Christoffel symbols
  • G(q)    = Gravity compensation vector, from link masses
  • Kp      = Proportional gains: [30, 100, 50] (configurable)
  • Kd      = Derivative gains: [4, 10, 5] (configurable)

THREE CONTROL MODES AVAILABLE:
  1. Full CTC          (--no args)          : Uses model + feedback
  2. Model-Based Only  (--no-feedback)      : Pure feedforward, no correction
  3. Feedback-Based    (--no-model)         : Pure error correction (traditional PD)

🔍 TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════════════════

INVERSE DYNAMICS IMPLEMENTATION:
  • Forward kinematics: Link centers of mass computation
  • Inertia matrix D(q): Jacobian-based from link geometry & masses
  • Coriolis C(q,q̇): From Christoffel symbols
  • Gravity G(q): From potential energy gradient
  • Robot: PUMA 560 with actual physical parameters
    - Link 2: 17.4 kg, 0.4318 m length
    - Link 3: 4.8 kg
    - DH parameters: d₂=0.2435m, d₃=-0.0934m

DATA INTEGRITY FEATURES:
  ✓ No future data leakage: All computations causal
  ✓ Time alignment: CSV and simulation synchronized
  ✓ Numerical stability: Double precision throughout
  ✓ Proper differentiation: np.gradient() for accelerations
  ✓ Torque saturation: Applied after all computations
